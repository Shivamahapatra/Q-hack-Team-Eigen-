## 3. Representative Case Studies

### Case 1: Self-Inverse & CX Cancellation with Identity Elimination

#### Input Circuit:
```
q_0: ──id──X──X──H──────■──■──
                        │  │  
q_1: ────────────id─────┼──┼──
                        │  │  
q_2: ──Z──Z─────────────X──X──
```

#### Metrics Before Optimization:
```
Total Gate Count: 9
Gate Breakdown: {'id': 2, 'x': 2, 'z': 2, 'h': 1, 'cx': 2}
Circuit Depth: 4
```

#### Optimization Summary:
- `RemoveIdentities`: Dropped 2 `id` gates on $q_0$ and $q_1$.
- `CancelSelfInverse`: Cancelled adjacent $X-X$ on $q_0$ and $Z-Z$ on $q_2$.
- `CancelAdjacentCX`: Cancelled redundant adjacent $CX(q_0, q_2)$ pair.

#### Metrics After Optimization:
```
Total Gate Count: 1
Gate Breakdown: {'h': 1}
Circuit Depth: 1
Gate Reduction: 88.9%
Depth Reduction: 75.0%
Unitary Distance: 0.0 (Fidelity = 1.0000)
```

### Case 2: Barrier Safety & Fence Non-Cancellation

#### Input Circuit:
```
q_0: ──H──░──H──
          ░     
q_1: ──X──░──X──
```

#### Optimization Analysis:
- Gates $H$ and $H$ on $q_0$ are separated by an explicit `barrier`.
- Gates $X$ and $X$ on $q_1$ are separated by the same `barrier`.
- **Observed Behavior**: The optimizer strictly respects the synchronization barrier; neither pair is cancelled.
- **Output Circuit**: Preserved completely intact with 4 gates, 1 barrier, depth 3.
